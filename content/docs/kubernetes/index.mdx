## Emergency Kubernetes Triage Cheat Sheet

| Symptom / Goal | Command | What It Does |
| :--- | :--- | :--- |
| **Check failing pods across cluster** | `kubectl get pods -A --field-selector=status.phase!=Running` | Lists all pods not currently in Running state across all namespaces. |
| **Why is pod crashing?** | `kubectl logs <pod> --previous` | Prints log output from the previous crashed container instance. |
| **Trigger zero-downtime reload** | `kubectl rollout restart deployment/<app>` | Gracefully restarts all pods in deployment one by one. |
| **Forward cluster port to local** | `kubectl port-forward svc/<name> 8080:80` | Maps localhost port 8080 directly into cluster Service port 80. |
| **Decode secret value** | `kubectl get secret <name> -o jsonpath="{.data.<key>}" \| base64 -d` | Extracts and decodes base64 secret key value directly to terminal. |
| **Terminal UI Dashboard** | `k9s` | Launches instant, full-screen ncurses terminal cluster manager. |
