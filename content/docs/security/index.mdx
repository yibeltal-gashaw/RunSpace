Welcome to the **Security & Secrets** operational reference for RunSpace. This section provides commands for auditing TLS handshakes and certificate expiration, generating self-signed wildcard certificates for local HTTPS development, scanning repositories for hardcoded API secrets, and auditing container images with Trivy.

---

## Security Rapid Cheat Sheet

| Task | Command | Purpose |
| :--- | :--- | :--- |
| **Check Remote Cert Expiration** | `openssl s_client -connect host:443 2>/dev/null \| openssl x509 -noout -dates` | Pulls remote certificate and prints `notBefore` and `notAfter` dates. |
| **Check Cert SAN Domains** | `openssl s_client -connect host:443 2>/dev/null \| openssl x509 -noout -ext subjectAltName` | Lists all domains and subdomains covered by the SSL certificate. |
| **Scan Git Repo for Leaked Secrets** | `gitleaks detect --verbose` | Scans commit history for exposed API keys, private tokens, and passwords. |
| **Scan Container Image for CVEs** | `trivy image --severity HIGH,CRITICAL nginx:latest` | Audits container packages against known vulnerability databases. |
| **Encrypt File with `age`** | `age -p secrets.env > secrets.env.age` | Password-protects sensitive configuration files with modern encryption. |
