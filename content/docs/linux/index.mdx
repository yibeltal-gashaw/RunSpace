## Emergency Triage Cheat Sheet

Quick one-liners for common server incidents:

| Incident / Symptom | Quick Triage Command | Purpose |
| :--- | :--- | :--- |
| **Disk is 100% full** | `df -h && du -ahx / \| sort -rh \| head -n 20` | Identify saturated partitions and top 20 storage hogs. |
| **Server frozen / 100% CPU** | `top -b -n 1 \| head -n 20` or `htop` | Pinpoint rogue processes pegging the CPU. |
| **Out of Memory crash** | `dmesg -T \| grep -i -E "oom\|killed process"` | Confirm if the Linux kernel OOM Killer terminated processes. |
| **Port conflict (`EADDRINUSE`)** | `ss -tulpn \| grep :<port>` or `lsof -i :<port>` | Find the PID holding the network socket. |
| **Kill process locking port** | `kill -9 $(lsof -t -i:<port>)` | Immediately free up the locked port. |
| **Follow service crash logs** | `journalctl -u <service> -f -n 100 --no-pager` | Stream the latest unit logs without opening a pager. |
| **Top traffic source in logs** | `awk '{print $1}' access.log \| sort \| uniq -c \| sort -nr \| head -n 10` | Find top IP addresses hitting an Nginx/Apache endpoint. |
| **Test remote TCP socket** | `nc -zv <host> <port>` | Verify reachability without establishing a full application session. |
