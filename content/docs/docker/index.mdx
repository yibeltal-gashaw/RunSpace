## Global CLI Options Reference

All Docker commands accept these root-level flags before the sub-command:

| Option | Syntax | Purpose |
| :--- | :--- | :--- |
| **Client Config** | `--config string` | Path to client configuration directory (defaults to `~/.docker`). |
| **Daemon Context** | `-c, --context string` | Select a named daemon connection context (overrides `DOCKER_HOST` env). |
| **Debug Mode** | `-D, --debug` | Enable verbose client-to-daemon communication debugging output. |
| **Daemon Socket** | `-H, --host list` | Target UNIX socket (`unix:///var/run/docker.sock`), TCP (`tcp://host:2376`), or SSH (`ssh://user@host`). |
| **Log Level** | `-l, --log-level string` | Client logging threshold: `debug`, `info`, `warn`, `error`, `fatal` (default: `info`). |
| **mTLS Security** | `--tlsverify` | Enforce mutual TLS validation against `--tlscacert`, `--tlscert`, and `--tlskey`. |
| **CLI Version** | `-v, --version` | Print Docker client version details and exit. |

## Complete Docker Command Matrix

| CLI Category | Commands Included | Primary Use Cases |
| :--- | :--- | :--- |
| **Container Execution** | `run`, `create`, `start`, `stop`, `restart`, `kill`, `rm`, `pause`, `unpause`, `wait` | Starting, stopping, freezing, auto-restarting, and deleting runtime containers. |
| **Container Triage** | `exec`, `attach`, `top`, `stats`, `port`, `diff`, `cp`, `rename`, `update` | Interactive shells, live resource monitoring, port inspection, filesystem diffs, dynamic hardware limits. |
| **Image Construction** | `build`, `builder`, `buildx`, `commit`, `history` | Multi-stage Dockerfile builds, BuildKit caching, multi-arch builds (`amd64`/`arm64`), layer size auditing. |
| **Image Distribution** | `images`, `rmi`, `tag`, `pull`, `push`, `search`, `login`, `logout` | Registry authentication, layer tagging, pulling by digest, pushing to Docker Hub, GHCR, or private ECR. |
| **Air-Gap & Tarballs** | `save`, `load`, `export`, `import` | Layered image archive bundling vs flat container filesystem snapshots for offline systems. |
| **Persistent Storage** | `volume` (`create`, `ls`, `inspect`, `rm`, `prune`) | Managed named volumes, bind mounts, in-memory `tmpfs`, automated backup/restore tar archives. |
| **Networking** | `network` (`create`, `ls`, `inspect`, `connect`, `disconnect`, `rm`, `prune`) | Bridge subnets, host mode, overlay networks, hot-plugging interfaces, container DNS resolution. |
| **System Management** | `system` (`df`, `prune`, `info`, `events`), `inspect`, `version` | Reclaiming disk space, inspecting daemon architecture, streaming crash events in real-time. |
| **Remote Contexts** | `context` (`create`, `use`, `ls`, `inspect`) | Switching between local Docker Desktop and remote production virtual machines via SSH. |
| **Clustering & Swarm** | `swarm`, `node`, `service`, `stack`, `secret`, `config` | Multi-host node clustering, replicated services, rolling updates, compose stack deploys, secrets mounting. |
| **Trust & Extensions** | `trust`, `manifest`, `plugin` | Digital image signing with Notary, multi-arch manifest lists, third-party storage/network plugins. |
