Deploy Portainer Community Edition (CE) server and Edge Agent nodes.

---

## 1. Deploy Portainer CE Server

Spin up the Portainer CE management server with a named persistent data volume and host Docker socket binding.

```bash
docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:latest
```

Once running, access the dashboard securely at:
- **HTTPS:** [https://localhost:9443](https://localhost:9443)
- **HTTP (Legacy / Tunnel):** [http://localhost:8000](http://localhost:8000)

---

## 2. Deploy Portainer Edge Agent

Run the standalone Portainer Agent on remote hosts to cluster them into a single centralized Portainer dashboard.

```bash
docker run -d -p 9001:9001 --name portainer_agent --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v /var/lib/docker/volumes:/var/lib/docker/volumes portainer/agent:latest
```
