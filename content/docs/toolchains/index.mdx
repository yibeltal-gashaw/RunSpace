Welcome to the **Toolchains & Task Runners** reference hub for RunSpace. This section documents how modern developers eliminate runtime version conflicts across polyglot repositories, automate project-level secrets loading without global pollution, and write clean, standardized task automation recipes.

---

## Toolchain Quick Comparison

| Tool | Purpose | Replaces / Improves | Config File |
| :--- | :--- | :--- | :--- |
| **mise** (or **asdf**) | Unified polyglot runtime manager | `nvm`, `pyenv`, `rbenv`, `gvm`, `sdkman` | `.mise.toml` / `.tool-versions` |
| **direnv** | Automatic directory-scoped env variables | Manual `export`, sourcing `.env` scripts | `.envrc` |
| **just** | Modern command runner for project recipes | `make`, `npm run`, messy bash scripts | `justfile` |
