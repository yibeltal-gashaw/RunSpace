Welcome to the **Modern Unix CLI** reference hub for RunSpace. The developer command line has evolved with faster, safer, syntax-highlighted, and interactive tools that respect `.gitignore` and work seamlessly across Linux, macOS, and Windows.

---

## Classic Tools vs. Modern Replacements

| Legacy GNU / POSIX Tool | Modern Rust/Go Replacement | Key Advantage | Command |
| :--- | :--- | :--- | :--- |
| `grep` | **ripgrep (`rg`)** | 10x faster, respects `.gitignore`, regex by default | `rg "pattern"` |
| `find` | **fd (`fd`)** | Simple intuitive syntax, colorized, fast directory walk | `fd -e ts` |
| `cat` | **bat (`bat`)** | Syntax highlighting, line numbers, git modifications | `bat app.ts` |
| `ls` | **eza (`eza`)** | Git status, tree hierarchy view, file icons | `eza -la --git` |
| `cd` | **zoxide (`z`)** | Smart directory jump learning from frecency | `z myproject` |
| `du` | **dust / gdu** | Interactive visual bar charts of disk hogs | `dust` / `gdu` |
| `top` / `htop` | **bottom (`btm`)** | Visual graphical CPU/RAM/process dashboard | `btm` |
| *(none)* | **fzf (`fzf`)** | Universal interactive fuzzy filtering for any list | `history \| fzf` |
