## Unix ↔ PowerShell Quick Translation

| Task | PowerShell Cmdlet / Snippet | Unix Analogue |
| :--- | :--- | :--- |
| **Kill by port** | `Stop-Process -Id (Get-NetTCPConnection -LocalPort <port>).OwningProcess -Force` | `kill -9 $(lsof -t -i:<port>)` |
| **Check open port** | `Test-NetConnection -ComputerName <host> -Port <port>` | `nc -zv <host> <port>` |
| **Make HTTP GET** | `Invoke-RestMethod -Uri <url>` | `curl -s <url>` |
| **Find in files** | `Get-ChildItem -Recurse \| Select-String -Pattern "<text>"` | `grep -rn "<text>"` |
| **Find command path** | `(Get-Command <cmd>).Source` | `which <cmd>` |
| **Split PATH** | `$env:PATH -split ";"` | `echo $PATH \| tr ':' '\n'` |
| **Execution timer** | `Measure-Command { <script> }` | `time <command>` |
| **Allow scripts** | `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned` | `chmod +x <script>` |
