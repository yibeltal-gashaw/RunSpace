## Database Rapid Triage Cheat Sheet

| Task | Command | Target Engine |
| :--- | :--- | :--- |
| **Stream Live Redis Operations** | `redis-cli monitor` | Redis |
| **Safe Key Search without Locking** | `redis-cli --scan --pattern "session:*"` | Redis |
| **Inspect Active Postgres Queries** | `psql -c "SELECT pid, query, state FROM pg_stat_activity WHERE state != 'idle';"` | PostgreSQL |
| **Kill Hanging Postgres Query** | `psql -c "SELECT pg_cancel_backend(<pid>);"` | PostgreSQL |
| **Check Largest Postgres Tables** | `psql -c "SELECT relname, pg_size_pretty(pg_total_relation_size(relid)) FROM pg_catalog.pg_statio_user_tables ORDER BY pg_total_relation_size(relid) DESC LIMIT 10;"` | PostgreSQL |
| **Inspect SQLite Schema** | `sqlite3 app.db ".schema"` | SQLite |
