Prevent accidental secret leaks into version control and audit container images for known vulnerabilities before deployment.

---

## 1. Secrets Auditing: `gitleaks`

Detect hardcoded passwords, AWS keys, Stripe tokens, and private SSH keys across git histories:

```bash title="gitleaks Workflows"
# Detect secrets in current git repository working tree and commit history
gitleaks detect --verbose

# Run pre-commit scan only on unstaged changes
gitleaks protect --verbose --staged

# Generate JSON report for CI/CD pipelines
gitleaks detect --report-path=gitleaks-report.json --report-format=json
```

---

## 2. Container Image & Filesystem Vulnerability Scanning: `trivy`

A comprehensive, fast security scanner for container images, filesystems, and Git repositories:

```bash title="Scan Container Images"
# Scan local or remote Docker image for High and Critical vulnerabilities
trivy image --severity HIGH,CRITICAL nginx:1.27

# Output scan results in a clean table ignoring unpatched vulnerabilities
trivy image --ignore-unfixed --severity HIGH,CRITICAL my-app:latest

# Scan filesystem / repository dependencies (package.json, go.mod, Cargo.lock)
trivy fs --security-checks vuln,secret,config .
```

---

## 3. Simple, Modern File Encryption: `age`

A modern, secure replacement for OpenSSL/GPG encryption with simple syntax:

```bash title="age Commands"
# Encrypt a file with a passphrase
age -p -o secrets.env.age .env.production

# Decrypt an encrypted file back to stdout or destination file
age -d secrets.env.age > .env.production

# Encrypt using a public key recipient
age -r age1ql3... secrets.env > secrets.env.age
```
