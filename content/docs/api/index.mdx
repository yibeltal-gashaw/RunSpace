## Rapid Diagnostic One-Liners

| Scenario | Command | Purpose |
| :--- | :--- | :--- |
| **Inspect Response Headers Only** | `curl -sI https://api.example.com` | Prints status code and HTTP headers without downloading body. |
| **Extract JSON Field** | `curl -s https://api.example.com/health \| jq -r '.status'` | Queries API and pulls raw `.status` field without quotes. |
| **Measure HTTP Latency** | `curl -w "@curl-format.txt" -o /dev/null -s https://api.example.com` | Breaks down DNS resolution, TCP handshake, TLS setup, and TTFB. |
| **Pretty Print JSON Pipe** | `cat response.json \| jq .` | Formats and colorizes JSON stream with syntax highlighting. |
| **In-place YAML Tag Update** | `yq -i '.services.web.image = "nginx:1.27"' docker-compose.yml` | Updates image tag directly without altering comments or formatting. |
