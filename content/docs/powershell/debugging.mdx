Common troubleshooting procedures for PowerShell script execution errors, permission boundaries, execution timing, and error inspections.

---

## 1. Fix: "running scripts is disabled on this system"

Activating Python virtual environments (`venv\Scripts\Activate.ps1`) or running `pnpm`/`npm` CLI scripts often triggers:
> `File cannot be loaded because running scripts is disabled on this system.`

Update the execution policy for your current user account without requiring Administrator privileges:

```powershell title="Set Execution Policy"
# Inspect current policies across all scopes
Get-ExecutionPolicy -List

# Allow local unsigned scripts and remote signed scripts
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
```

### Policy Scopes Hierarchy

| Scope | Description |
| :--- | :--- |
| `Process` | Affects only the current PowerShell window/terminal. |
| `CurrentUser` | Persists for your user profile in the Windows registry (No Admin required). |
| `LocalMachine` | Applies machine-wide to all users (Requires Administrator rights). |

## 2. Unblock Downloaded Scripts

Windows marks files downloaded from web browsers with an alternate data stream security identifier (`Zone.Identifier`):

```powershell title="Remove Download Security Zone"
Unblock-File -Path .\setup.ps1
```

---

## 3. High-Precision Command Benchmarking

Measure exact execution duration for builds, bundling, tests, or scripts:

```powershell title="Measure-Command"
Measure-Command { npm run build }
```

**Output Breakdown:**
- `TotalSeconds`: Overall duration in seconds.
- `TotalMilliseconds`: Exact millisecond precision.

---

## 4. Inspect Detailed Error Stack Traces

When a PowerShell command fails, inspect the last error record's deep exception details:

```powershell title="Inspect Last Error Record"
$Error[0] | Format-List * -Force
$Error[0].Exception.Message
$Error[0].ScriptStackTrace
```

---

## 5. Launch Elevated Administrator Session

Relaunch PowerShell with administrative privileges from an unprivileged shell:

```powershell title="Start Elevated Prompt"
# For modern PowerShell 7+
Start-Process pwsh -Verb RunAs

# For legacy Windows PowerShell 5.1
Start-Process powershell -Verb RunAs
```
