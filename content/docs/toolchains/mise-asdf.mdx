`mise` (formerly `rtx`) is a blazing-fast, Rust-based polyglot tool version manager fully compatible with `.tool-versions` (`asdf`).

---

## 1. Daily `mise` Workflows

Manage all development runtimes without installing dozens of separate version managers:

```bash title="Installing & Pinning Runtimes"
# Install specific Node.js, Python, and Go versions
mise use node@22
mise use python@3.12
mise use go@1.23

# Pin version locally to current directory (writes to .mise.toml)
mise use --local node@20.18.0

# Pin version globally for your user profile
mise use --global node@22.0.0

# Install all runtimes specified in existing repository config
mise install

# List installed runtime versions
mise list
```

---

## 2. Configuration Files (`.mise.toml` vs `.tool-versions`)

```toml title=".mise.toml"
[tools]
node = "22"
python = "3.12"
golang = "1.23"
terraform = "1.9"

[env]
NODE_ENV = "development"
PORT = "3000"
```

```text title=".tool-versions (Standard asdf compatibility)"
nodejs 22.11.0
python 3.12.7
golang 1.23.2
```

---

## 3. Running One-Off Commands in Specific Versions

Execute binaries against specific runtime versions without changing environment defaults:

```bash title="One-Off Version Execution"
# Run command with Node 18
mise exec node@18 -- npm test

# Run Python script under specific Python version
mise exec python@3.10 -- python script.py
```
