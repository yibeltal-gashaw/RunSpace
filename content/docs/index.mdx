## Omni-Search Router Syntax

The global search bar at the top acts as an omni-router. Use prefix shortcuts to query developer repositories directly:

| Prefix | Target Engine | Example Query | Direct Destination |
| :--- | :--- | :--- | :--- |
| `d:` | **Docker Hub** | `d: redis alpine` | `hub.docker.com/search?q=redis+alpine` |
| `gh:` | **GitHub** | `gh: waku` | `github.com/search?q=waku` |
| `so:` | **StackOverflow** | `so: docker socket permission` | `stackoverflow.com/search?q=docker+socket` |
| *(none)* | **Google Search** | `tailscale exit node guide` | `google.com/search?q=tailscale...` |
