## Quick Reference Cheat Sheet

```bash title="Essential WSO2 Log Search Commands"
# Stream real-time logs (suppress info, errors only)
tail -f repository/logs/wso2carbon.log | grep --line-buffered -E "ERROR|FATAL|Exception"

# Search active log by Correlation ID
grep -F "c8a45f92-9a3b-4822-83b5-312948e7150a" repository/logs/wso2carbon.log

# Search compressed rotated archives (.gz) without extracting
zgrep -F "c8a45f92-9a3b" repository/logs/wso2carbon-*.log.gz

# Search errors with 10 lines of stack trace context
grep -n -C 10 "ERROR" repository/logs/wso2carbon.log

# Filter slow transactions (> 2000ms) in correlation log
awk -F'|' '$5 > 2000 {print "Duration: "$5"ms | Method: "$6" | Path: "$7}' repository/logs/correlation.log

# Search HTTP access logs for 4xx and 5xx errors
awk '$9 >= 400 && $9 <= 599 {print $1, $4, $7, $9}' repository/logs/http_access_*.log
```
