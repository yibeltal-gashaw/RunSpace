Welcome to the **SSH & Tunneling** operational reference for RunSpace. This section covers establishing encrypted bridges between local environments and remote infrastructure, accessing air-gapped databases, and exposing local services to public webhooks without firewall modifications.

---

## Port Forwarding Quick Reference

| Forwarding Type | Flag | Typical Scenario | Example Command |
| :--- | :--- | :--- | :--- |
| **Local Port Forward** | `-L` | Access remote internal DB from localhost | `ssh -L 5433:localhost:5432 user@bastion` |
| **Remote Port Forward** | `-R` | Share local dev server with remote client | `ssh -R 8080:localhost:3000 user@vps` |
| **Dynamic SOCKS Proxy** | `-D` | Route browser traffic through remote host | `ssh -D 1080 -N -C user@vps` |
| **Bastion Jump** | `-J` | Access target server through an intermediary | `ssh -J bastion.corp target-internal` |
| **Public Webhook Tunnel** | *Cloudflare* | Expose localhost to public HTTPS instantly | `cloudflared tunnel --url http://localhost:3000` |
