## Git Emergency Cheat Sheet

| Incident / Symptom | Solution Command | What It Does |
| :--- | :--- | :--- |
| **Committed to wrong branch** | `git reset --soft HEAD~1` | Undoes the commit but leaves all modified files staged in index. |
| **Accidental `git reset --hard`** | `git reflog` then `git reset --hard HEAD@{n}` | Rewinds working tree back to the recorded reflog position. |
| **Forgot to add file to last commit** | `git add <file> && git commit --amend --no-edit` | Merges new change into the most recent commit without modifying message. |
| **Need to discard all uncommitted changes** | `git restore . && git clean -fd` | Wipes modified tracked files and deletes untracked files/directories. |
| **Deleted branch by mistake** | `git checkout -b <branch> <commit-hash-from-reflog>` | Recreates branch pointer at the commit hash prior to deletion. |
| **Stash popped with conflicts or dropped** | `git fsck --lost-found \| grep commit` | Identifies orphaned commits including dropped stash objects. |
